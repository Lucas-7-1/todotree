## 验证

- `npm test`：34 个工作流/界面测试、9 个持久化测试、6 个 Android 桥接单测。
- `npm run build`：TypeScript 和生产构建。
- `PLAYWRIGHT_MODULE=<playwright module path> node tests/mobile-browser-smoke.cjs`：真实 Chromium 手机视口 360/393/430，含新增、孙任务、分支保留、批量完成、重载回读、报告、日历以及键盘布局模拟，生成截图与录屏。
- Android instrumented tests：使用真实 WebView、SQLite 和 Keystore；截图必须导出并进入构建产物。运行结果以 Actions 对应提交为准。

## 仍需明确的限制

- Chromium 缩短视口只能验证键盘布局，不能代替具体 vivo 机型上的软键盘验证；Android 模拟器检查结果与真机结果分开记录。
- 本次限制了移动列表的渲染数量；现有数据层和完成日历仍会读取工作区/事件集合，尚未改造成数据库按月分页查询。不能声称 50,000 历史记录下已达到真机 60fps。
- 搜索当前在项目视图覆盖全部活动项目路径，尚未增加“仅当前项目”的范围选择器。
- 排序偏好在当前会话保留，暂不跨重启保存。
- 本版保持本地数据模型和应用身份；不提供手机与电脑自动同步。
