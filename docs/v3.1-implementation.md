# TodoTree 四项接入 · preview.10

本次沿用 v3.1 四项功能 PRD，在现有三个模式的编辑器与连接设置中补齐流程。

- 地点：高德关键词／城市／按需附近搜索，20 条分页，具体分店确认，手写地址，公开分享链接，最近 20 个确认地点。附近位置临时从 WGS84 经官方接口转为 GCJ-02，不保存用户当前位置。原始来源名称与地址另存快照。子事件仍独立指定地点，移动节点不改写地点。
- 食品：USDA 在线、官方 SR Legacy 7,793 条离线参考、Open Food Facts 条码、个人标签及用户配方。每 100g／100ml／份严格分开；份量换算需要明确每份重量或体积；kJ 使用 4.184 转换。OFF 旧式字段无法明确克／毫升时，先保持未知，由用户按实际包装确认。配方保存原料与用油快照、实际成品量，营养或用量缺失时总能量保持未知。
- IM：系统分享、系统日历／ICS、飞书机器人。测试目的地后显式启用，自动提醒绑定 Webhook 指纹；消息仅含任务名称、项目路径、提醒时间与打开待办链接。仅明确的 HTTP 429／503 最多自动重试一次；超时或未知结果不会自动重发。没有部署常在线云调度，关机／断网仍可能错过本机发送。
- 原生提醒：任务事实和待登记提醒同一 SQLite 事务；启动、重启、时间变化与权限广播核对。完成、归档、删除、改期取消旧规则；通知可延后 5 分钟，最多三次，旧操作幂等。错过时刻合并提示，不集中补发。
- 训练休息：仅在用户开始休息后运行的 specialUse 前台服务、单调时钟与有时限的 CPU 唤醒锁，结束后释放；不依赖连续 setExactAndAllowWhileIdle。暂停、延长、跳过和结束重新核对已保存版本，重启不恢复旧开机计时。计时不生成次数，也不自动开始下一组。配置页提供 30／60／120 秒本机锁屏测试和用户确认状态；系统计时器是独立入口。

## 数据与升级

release 使用原包名 com.lucas.todotree、versionCode 10，发布时沿用既有签名。
任务备份仍为 schema 2，原 schema 1／2 兼容回归保留；健康及连接备份升级到 schema 2 并接受旧 schema 1，防止旧版本误读新增营养单位。数据库旧记录不重写，历史营养快照不受个人标签或在线数据更新影响。连接普通备份不含凭证，恢复后飞书需重新验证。

## 验证边界

单元与浏览器测试覆盖份量、配方、快照、备份、分店确认、取消请求、跨页面草稿、移动宽度与提醒导入默认暂停。Android 仪器测试包含真实 SQLite、Keystore、广播取消、去重、前台计时停止，以及三个短计时在锁屏／强制 Doze 下连续运行。

模拟器结果不能替代具体手机品牌的真机验收。高德／正式 USDA Key、飞书真实目的地需用户在安装版填写后联调。食品数据可查询不等于中国食物／做法匹配准确；代表性 200 项覆盖验收尚未完成，食品能力维持测试版标识。官方公开数据不包含未经授权的中国营养库或私有平台订单。
