# TodoTree v3.1 接入预览版

本版让手帐地点、饮食来源和具体待办提醒能够实际配置并使用。第三方服务需要自己的凭证和可用网络；没有凭证也能继续手动记录。

## 使用入口与范围

| 功能 | 使用入口 | 当前行为 |
| --- | --- | --- |
| 门店与地点 | 手帐编辑器 → 地点 | 高德 Web 服务地点搜索，显示同名分店和地址；选择后再次确认。也可手写地点或粘贴公开分享文本。保存门店 ID、地址、GCJ-02 坐标与来源。 |
| 接收分享 | 其他 Android 应用 → 分享 → TodoTree | 收到文本后询问是否存为手帐草稿；不会自动发布、生成消费或改变当前训练。 |
| 食品来源 | 健康 → 饮食 → 来源选择 | USDA 食材查询、Open Food Facts 包装条码查询、离线个人标签。每次选择保存来源与当时营养值。 |
| 具体待办提醒 | 待办详情 → 提醒与分享 | 设置当前任务的一次性提醒时间。Android 原生 AlarmManager 提醒；完成、归档、删除、改期和暂停后取消旧提醒。 |
| 飞书机器人 | 连接与提醒 → 办公提醒 | 用户明确测试并核对目的地后才可开启。提醒绑定目的地指纹；更换机器人后须重新保存旧规则，避免误发到新群。 |
| 系统分享与日历 | 待办详情 → 提醒与分享 | 打开系统分享面板或日历编辑页，由用户确认。网页提供分享/复制或 ICS 文件。 |
| 配置与权限 | 设置 → 连接与提醒；或地点/食品来源设置 | 配置高德、USDA、飞书；检查通知渠道和准时提醒权限；导出不含凭证的个人标签与公开配置。 |

分享链接只保留白名单内的公开 HTTPS 地址，不请求该链接，不爬取私人订单。高德搜索需要有效的 Web 服务 Key。USDA 未配置正式 Key 时使用受限 DEMO 查询。包装食品采用 OFF v3.6 单商品接口，仅支持条码查询，不承诺中国食品、餐馆菜品或所有做法的完整覆盖。

## 营养计算口径

- 明确提供每 100g 能量时，按输入克重计算热量。
- 每 100ml 标签不直接按克重计算；未提供单位或能量时显示“未知”。保留名称与克重，仍可保存记录。
- 零热量与未知分开保存。kJ 按 4.184 换算为 kcal，不根据图片、菜名或品牌猜测营养。
- 来源收藏最多 200 条；查询缓存最多 60 条、15 分钟。查询必须手动触发，取消过期请求，429 冷却且不循环重试。
- 本版摄入记录保持原有克重结构，尚未增加毫升、份数或食谱配比录入。

## 提醒与数据保护

本机待办在已有 SQLite 事务提交后再设置系统提醒；提醒失败不会把已保存任务误报成未保存。只处理变更中实际带提醒的任务。发送前核对数据库中的任务状态、提醒版本和目的地；以任务、提醒版本和渠道形成唯一发送记录，先认领后发送。结果未知时不自动重发，避免重复通知或群消息。最近记录最多显示 20 条，保留 31 天。

锁屏提醒依赖系统通知开关、准时权限及厂商后台策略。没有准时权限时使用可能延迟的提醒。应用启动、开机、时间调整与权限重新开放时重建未来提醒。过期超过 24 小时不补发；强制停止、关机、断网以及后台限制仍可能影响送达。飞书接受请求不等于用户已阅读。

备份恢复默认暂停导入的提醒，不自动启用旧群推送。复制任务和生成下一次重复实例不沿用旧提醒。点击通知只打开任务，不自动完成；切换模式或通知跳转前等待编辑器保存草稿，失败时保留原页面。分享进入当前编辑器时只保存新草稿，保留当前记录和训练。

连接配置独立保存：Android 使用 SQLite 与 Android Keystore AES-GCM；网页公开配置使用 IndexedDB 版本校验，凭证只在当前标签页会话保存。多个页面冲突时拒绝覆盖。读取或解密失败不清空数据，明确重置凭证会保留个人标签和业务记录。普通备份不包含 Key、Webhook 或 Secret。

## 安装与迁移

本次可安装 APK 是独立预览包 `com.lucas.todotree.lifev31`，版本 `1.0.0-integrations-preview.9`。旧预览包使用不同签名和包名，本包与其并存，不是可直接覆盖的正式升级包。

1. 保留旧应用，分别导出待办 JSON、手帐与原图 ZIP、健康 JSON。
2. 安装新预览版，分别在对应入口恢复，并核对条目及照片。
3. 重新填写第三方凭证，并检查提醒权限；导入的提醒需要逐条核对后启用。

任务 JSON 不包含手帐照片和健康记录；连接标签另外备份。本次不改动三域历史数据格式，也不自动云同步。正式发布需要固定、由项目所有者保管的签名密钥；不能通过卸载旧应用解决签名不一致。

## 验证

`npm test` 覆盖既有任务闭环、撤销、持久化、旧备份以及新的来源单位、分享链接、目的地绑定、提醒生命周期与草稿跳转保护。`tests/connections-browser.cjs` 使用模拟第三方响应，验证手机宽度、门店确认、三种食品来源、刷新恢复、跨页面冲突、导入暂停提醒以及即时草稿保存。现有四组浏览器回归继续执行。

Android `ConnectionsTest` 使用真实 SQLite、Keystore、PendingIntent 和通知广播，检查加密保存、版本冲突、重启读取、重复发送抑制以及完成/删除/移除规则后的取消；测试不调用真实飞书。

真实高德/USDA/飞书目的地及实体手机锁屏、重启和厂商省电测试需要在实际配置后完成。自动化测试通过不代表上述真实环境已经验证。
