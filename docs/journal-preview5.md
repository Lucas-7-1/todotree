# 生活手帐 · Android preview.5

## 使用

- 更多 → 生活手帐；今天页面的更多操作也可直接记一笔。
- 日期默认今天；日历选择过去日期后点“补记”。文字、照片、感受或评分任一项即可保存。
- 日历查看每天事件；时间线、中文搜索、日期/手帐本/图片/评分筛选用于回溯。
- 编辑中自动保存草稿；正式记录才计入日历。离开编辑会保留草稿。
- 更多 → 导出手帐与原图，生成 ZIP。任务 JSON 备份不含手帐。
- 原图保存到应用私有文件目录，删除系统相册中的原文件不会影响已导入照片。
- 本版本为本机离线存储；卸载/清除应用数据会删除本地内容，请先导出 ZIP 到应用外。

## 边界与实现

手帐与任务完全独立：不参与四象限、任务闭环、完成统计或工作复盘。原任务、树状拖动和底部导航保留。

Android 使用独立 journal.db、entries/books/drafts/attachments/refs/operations 表；原图为内容哈希命名的独立文件，预览可重新生成。写入原图后才提交引用；每张导入照片在原生端绑定草稿后才返回前端，避免选图后进程退出丢引用。发布、软删除、恢复、合并导入使用数据库事务和操作编号，发布附带版本检查。

事件自然日与记录创建时间分开；时区变化不修改 event_date。日历按事件日期聚合。月历只读取计数；事件分页每页20条，并使用游标，避免无限滚动累积图片和DOM。列表只取摘要，详情按需加载。图片串行采样到2048px预览、640px缩略图，不在工作区JSON中存base64。

删除先入独立回收站，可恢复或撤销。永久删除需二次确认；仍被其他事件、草稿或手帐本封面引用的原图保留。无引用文件超过24小时后在下次启动清理，正式记录不会自动过期。

ZIP保存记录、草稿、手帐本、回收站和引用原图；恢复先验证格式、路径、图片大小和SHA256。导入前生成本地检查点，冲突记录生成副本；同一备份重复恢复幂等。该检查点位于应用内部，不能替代用户导出到应用外的备份。

浏览器预览使用独立IndexedDB；ZIP备份和系统相机以Android版为交付范围，浏览器明确提示使用Android。未实现跨设备同步、AI手帐总结、地图、视频或自由拼贴。

## 验证入口

- npm test：既有回归 + journal模型日期、内容、筛选与排序。
- PLAYWRIGHT_MODULE=/path/to/playwright node tests/journal-browser-smoke.cjs：浏览器图文录入、刷新、补记、搜索、删除撤销、草稿和任务数据隔离；测试图片随仓库提供。
- JournalStoreTest：原生重开、事务幂等、版本冲突、原图共享引用、ZIP恢复与坏包保护、一万事件/一千原图月历查询。
- MobileLayoutTest：真实Android WebView手帐日历、原图预览、详情与软键盘截图；既有今日页及树状拖动回归仍执行。
