# USDA SR Legacy offline reference

Source: USDA FoodData Central SR Legacy CSV, April 2018 release.
Download: https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_sr_legacy_food_csv_2018-04.zip
FoodData Central documentation: https://fdc.nal.usda.gov/data-documentation.html
USDA data are public domain (CC0). English descriptions and FDC IDs are unchanged.
Only nutrient 1008 (Energy, kcal per 100g edible portion) is extracted; missing values remain null.
Chinese search aliases are search hints; they do not assert that a particular cooking method or Chinese mixed dish is nutritionally equivalent.
No representative 200-food coverage or mainland mixed-dish accuracy claim has been made.
